# PSE em Ação

## Sistema de Planejamento e Acompanhamento de Ações de Atividade Física na Escola

Projeto desenvolvido para a Atividade de Estudo Programado (AEP) do curso de Engenharia de Software da UniCesumar.

## 📌 Sobre o projeto

O **PSE em Ação** é um sistema desenvolvido em linguagem C com o objetivo de auxiliar no planejamento e acompanhamento de ações de promoção da atividade física realizadas no ambiente escolar.

O sistema permite cadastrar ações, consultar as ações registradas, pesquisar informações, atualizar a situação das ações e gerar um resumo dos resultados obtidos.

## 🎯 Objetivo

Desenvolver uma solução simples para auxiliar equipes escolares no registro, organização e acompanhamento de ações relacionadas à promoção da atividade física.

## ⚙️ Funcionalidades

- Cadastro de ações;
- Listagem das ações cadastradas;
- Pesquisa de ações por código, escola ou tema;
- Atualização da situação da ação;
- Registro da quantidade efetiva de participantes;
- Geração de resumo das ações realizadas;
- Validação dos dados informados.
